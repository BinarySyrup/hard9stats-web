# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning where practical.

## [Unreleased]

## [1.1.0] - 2026-10-27

### Added
- Clickable PDF report links for all four 2026 MLB postseason rounds, including the World Series.
- Styling for report links and accessible labels indicating that reports open in a new tab.

### Changed
- Updated the postseason tracker and README to show that all four 2026 reports are available.

### Removed
- Removed `LICENSE.txt` file as duplicate.

## [1.0.0] - 2026-10-08

### Added
- Initial `README.md` with setup, build, and project structure documentation.
- Standardized `.gitignore` entries for Node/Webpack, IDE, logs, and environment files.
- Added `CHANGELOG.md` to track project changes.
- Updated licensing to Apache-2.0 across `LICENSE.txt`, `package.json`, and `README.md`.
- MLB postseason tracker with round-by-round PDF report placeholders.
- League navigation with coming-soon states for NFL, NHL, and NBA.
- Responsive Hard9Stats branding with the supplied wordmark and dice icon.
- React, React DOM, Vite, and the React plugin pinned to release versions.
- Node.js `24.13.0` runtime requirement.
